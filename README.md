# Burp Suite Basics

## Description
Beginner level practice using Burp Suite Community Edition.

## Tools Used
- Burp Suite Community Edition
- Built-in Burp Browser

## Practice Done
- Intercepted HTTP requests
- Observed GET and POST requests
- Forwarded requests using Proxy

## Learning Outcome
- Understood how Burp intercepts web traffic
- Learned basics of web request analysis
